# Pi Plus：从地面被动稳定态学习接触图式，并规划起身

已实际运行 MuJoCo、采集接触探索数据、训练注意力动力学网络，并完成关节力矩驱动的起身。**当前成功方案包含显式物理校验和站立控制器；纯神经网络想象规划尚未完成起身。**

- 推荐先看：[新俯卧状态的混合规划起身录像](ground_results/hybrid_getup_prone_101.mp4)。这是训练未使用的初始状态，15 段图式动作共 9 s，随后 5 s 站立控制；录像为 2.4 倍速。
- 物理搜索得到的原始两个起点：[俯卧起身](ground_results/getup_prone.mp4)、[仰卧起身](ground_results/getup_supine.mp4)。这些录像不是纯神经规划的结果。
- [接触力／质心／关节受力曲线](ground_results/getup_contact_trace.png)、[预测效果](ground_results/contact_prediction.png)、[各关节图式的独立探测效果](ground_results/schema_effects.png)。
- 完整机器可读结果：[summary.json](ground_results/summary.json)。代码、数据、权重和录像打包于 `pi_plus_ground_schema.zip`。

## 实际实现的闭环

1. **被动稳定态。** 将机器人以俯卧或仰卧姿态放到平地，关节电机力矩为零，允许重力、关节阻尼和接触自然作用。持续约 0.6 s 满足动能 < 0.002 J、基座速度向量范数 < 0.03、最大关节速度 < 0.15 rad/s 后，才开始探索。范数混合线速度和角速度，仅为数值停止判据。24 个数据采集初始状态全部满足判据；不是靠冻结基座得到稳定。
2. **有界图式探索。** 使用 12 种双侧／差分关节协同，每个动作持续 0.6 s。关节目标为 `q_target = clip(q_now + B @ action)`，在前 0.25 s 平滑过渡，随后保持。包括髋屈伸、膝屈伸、踝屈伸、髋展开／扭转、肩部／肘部协同。12 个协同不是 24 个关节的独立全覆盖；头、腕和踝滚转等没有独立动作维度。
3. **记录身体与接触。** 每个身体节点记录角度、速度、电机力矩、地面接触引起的广义关节负载、连杆质心位置、地面三维接触合力、接触位置和接触标志。全局记录基座姿态／速度、全身质心位置／速度、骨盆高度等。
4. **注意力学习。** 输入当前身体／接触状态及候选图式动作，预测 0.6 s 后的身体状态、接触力、接触位置、关节负载和质心变化。对同一状态提出多个动作，即可比较预期效果。
5. **面向起身的想象规划。** 目标同时包含质心高度、骨盆高度、躯干竖直程度、足部承重、质心速度等。只奖励质心升高时，搜索会找到“躯干躺着、把腿抬高”的动作，因此不能仅靠质心高度奖励实现起身。
6. **接入站立控制。** 足部具备承重条件后，用有浮动基座动力学、摩擦及力矩约束的全身 QP 控制器完成竖立和稳定。执行全程由关节电机驱动；没有基座升力、悬挂、焊接或在执行过程中重置位姿。

模型估计的是：

```text
当前关节与身体状态 + 当前接触状态 + 候选关节协同
                         ↓ 具有 URDF 图先验的注意力模型
未来关节运动 + 未来接触力/关节负载 + 未来质心/骨盆/姿态
                         ↓ 目标与支撑条件评价
选动作 → 执行关节力矩 → 读取新的身体和接触状态
```

成功的混合规划额外使用 MuJoCo 克隆状态做未来物理校验。这是内部显式动力学模型的作用，不能算作网络独立学会了起身。

## 感知量的物理含义

每个地面接触的局部六维接触力转换到世界坐标，并统一取“地面对机器人”的方向；按连杆聚合。地面引起的广义负载为：

```text
Q_ground = sum(J_position.T @ F_ground + J_rotation.T @ M_contact)
```

只取其中的 24 个关节分量作为 `ground_joint_load`。它不是电机电流，也不是含重力、惯性、内部约束在内的全部关节负载。模型同时输入实际电机力矩，二者分别记录。

当前实现使用**理想仿真触觉／受力代理和模型提供的全身质心状态**。没有从仅有关节编码器、IMU、电机电流的观测中反演全部接触力；也没有证明这些接触变量在真机上都可辨识。全身触觉、足底传感器或一个另行验证的接触估计器，才能为硬件提供相应输入。

## 网络、数据与训练

- 官方 Pi Plus URDF：24 个转动关节 + 浮动基座，名义质量 11.0002354 kg。
- 25 个身体节点 token + 1 个平地 token + 1 个全局 token；2 层 Transformer，隐藏维度 48、4 个注意力头，每个网络 44,102 个参数。
- URDF 的质量、惯性、关节轴及连杆偏移作为节点先验。父子连杆之间使用较高注意力先验，其余身体节点仍可相互注意；不是硬性限制只能看邻接节点。
- 输入 398 维状态 + 12 维图式动作；输出状态增量及接触概率。力矩／力先做 `asinh(value/10)` 变换，再按训练数据标准化。损失为加权 Smooth L1 与接触分类 BCE。
- 3 个独立初始化的模型各训练 45 个 epoch，按验证损失保存最佳权重。在 CPU 上串行训练的总墙钟时长约 544 s，无 GPU。集成分歧用于候选惩罚，**没有校准为置信区间**。
- 随机／单轴探索：24 个被动落地状态 × 12 段探索轨迹 × 每段 6 步 = 1,728 对状态转换。
- 原始俯卧、仰卧两个起点的目标导向物理搜索另提供 8,992 对训练转换。它们是实际仿真得到的身体经验，没有外部起身动作捕捉参考。
- 训练共 10,144 对；验证 288 对；测试 288 对。按被动初始状态分组切分，测试只有 **4 个独立初始状态**，不能把 288 对视为 288 次独立起身实验。
- 后续混合规划产生的数据保留在结果目录，但未加入上述模型训练；没有用测试执行结果反向训练本次权重。

### 预测结果

| 0.6 s 预测指标 | 注意力集成 | 保持当前状态不变 |
|---|---:|---:|
| 质心高度 RMSE | 8.38 mm | 10.66 mm |
| 骨盆高度 RMSE | 8.95 mm | 14.53 mm |
| 关节角 RMSE | 0.063 rad | 0.178 rad |
| 地面广义关节负载 RMSE | 1.41 Nm | 1.77 Nm |
| 所有节点三维接触力分量 RMSE | 5.86 N | 7.13 N |
| **实际接触节点**的竖直力 RMSE | **19.69 N** | **20.44 N** |

接触分类 F1 为 0.742。实际质心高度变化超过 2 mm 的 200 个样本中，方向判断正确 175 个，即 87.5%。接触位置三维误差约 128 mm，明显不足以据此单独安排支撑切换。

按 48 段测试轨迹从初始状态递归预测，1.8 s 质心高度 RMSE 为 14.57 mm，3.6 s 为 14.21 mm。这些是当前探索分布的指标，不能作为任意起身动作的误差上界。

打乱动作输入后质心 RMSE 变为 9.67 mm；将当前力输入清零后关节负载 RMSE 变为 1.68 Nm。模型使用了动作和接触信息，但收益有限。这是输入干预诊断，不是重新训练的严格消融，也不是“注意力权重证明因果关系”。

## 起身实验的真实结果

| 方法 | 测试起点 | 完成站立 |
|---|---|---:|
| 显式物理搜索图式序列 + QP | 原始俯卧、仰卧，各 1 个 | 2/2 |
| 固定序列转移 | 新俯卧／仰卧各 3 个 | 0/6 |
| 纯注意力模型 CEM 规划 + 可用的 QP 接管 | 新俯卧、仰卧，各 1 个 | 0/2 |
| 动作记忆附近的神经预测修正 + QP | 同上 | 0/2 |
| **注意力候选筛选 + 显式物理校验 + QP** | 同上 | **1/2：俯卧成功，仰卧失败** |

所有成功试验使用同一终点判据：末尾连续 1 s 内，骨盆高于 0.30 m、躯干竖直分量 > 0.95、双脚竖直承重 > 80 N、非足部承重 < 5 N、质心速度 < 0.12 m/s。

成功的新俯卧状态（seed 101）：

- 网络在每个候选状态预测 64 个动作，选 8 个高分动作并保留 4 个探索动作；对这 12 个动作使用克隆 MuJoCo 状态校验。宽度 14 的 beam search 在第 16 轮找到可接入站立的状态，共 2,520 次物理展开。
- 本机搜索及复放约 135 s 墙钟时间，属于离线规划，未达到实时控制速率。
- 选出的 15 段动作连续执行 9 s，再用 5 s QP 站立。连续复放与搜索终点的 q/v 最大差为 0，排除了分支状态恢复错误造成的伪成功。
- 末态骨盆高 0.3469 m、质心高 0.2938 m、躯干竖直分量 0.9981、双脚承重 109.25 N、其他连杆承重 0 N、质心速度 0.00045 m/s。
- 新仰卧状态在 3,864 次物理展开后仍未找到成功起身；结果、轨迹和日志均保留。

没有做相同搜索预算的随机候选对照，不能据此声称注意力筛选提高了搜索效率。当前能确认的是“训练出的接触模型参与了一个完成起身的混合规划流程”，不能确认“网络独立掌握了通用起身技能”。

## 仿真假设与当前边界

地面为平面；摩擦 0.8、关节阻尼 0.08、armature 0.003、接触时间常数 0.008 s、电机一阶延迟 0.015 s 均为工程假设。使用名义 URDF 惯性，未同时加入之前质量／质心误差实验的扰动。编码器视为已经校准，未在本轮起身中重新执行零位辨识。

电机力矩按 URDF 上限约束，并使用随转速下降的驱动力矩包络。**这不是硬性关节速度限幅**：重力、惯性或接触可使关节被动超速。原始两条成功轨迹的速度峰值分别达到 URDF 数值的 1.15 倍和 1.10 倍；软关节限位最大穿透约 0.015 / 0.017 rad。新俯卧混合规划成功轨迹的对应值为 **1.28 倍和 0.042 rad**。因此结果是当前 MuJoCo 模型下的起身证据，不是所有实机执行约束都已满足的证明。

本轮没有传感器噪声、复杂地形、碰撞损伤模型或全参数随机化。没有解决此前的持续行走失败，也没有实现在线更新网络、未知地面辨识或从任意跌倒姿态起身。

## 复现

Python 3.12 环境中：

```bash
python -m venv .venv
.venv/bin/pip install -r requirements-ground.txt
export OPENBLAS_NUM_THREADS=1
.venv/bin/python build_model.py
```

`build_model.py` 会使用包内官方 URDF／网格重建本机路径的场景；不要直接复用其他机器生成的绝对路径 XML。

读取现有权重做一次想象预测，复放成功动作并检查实际物理积分：

```bash
.venv/bin/python predict_ground.py
.venv/bin/python ground_replay.py --pose prone --hybrid --seed 101
.venv/bin/python ground_replay.py --pose prone
.venv/bin/python ground_replay.py --pose supine
.venv/bin/python ground_checks.py
.venv/bin/python render_ground.py
```

从头采集、探索与训练：

```bash
.venv/bin/python ground_schema.py
.venv/bin/python ground_explore.py
.venv/bin/python ground_search.py --pose prone --depth 22
.venv/bin/python ground_search.py --pose supine --depth 22
.venv/bin/python ground_model.py --epochs 45
.venv/bin/python ground_diagnostics.py
```

重新做新状态的两种规划：

```bash
.venv/bin/python ground_imagine.py --pose prone --seed 101 --steps 20
.venv/bin/python ground_hybrid.py --pose prone --seed 101 --depth 24
.venv/bin/python ground_hybrid.py --pose supine --seed 101 --depth 24
.venv/bin/python render_ground.py --mode hybrid --poses prone
.venv/bin/python summarize_ground.py
```

重复命令会重写对应同名结果。随机种子固定；MuJoCo、求解器版本变化可能改变接触分支，建议保留原包中的轨迹作为对照。

## 文件接口

- `ground_schema.py`：物理环境、被动稳定判定、接触观测、12 个动作基、完整快照恢复。
- `ground_explore.py` / `ground_search.py`：无动作参考的探索及显式物理搜索。
- `ground_model.py` / `predict_ground.py`：训练、集成预测及最小调用示例。
- `ground_imagine.py`：纯神经 CEM，3 × 0.6 s 预测时域、192 个序列、4 轮、24 个 elite。
- `ground_memory.py`：成功探索记忆附近的神经候选修正。
- `ground_hybrid.py`：注意力候选提案、显式物理校验、连续复放。
- `ground_balance.py`：站立 QP 接管，保留当前膝弯曲方向和手臂姿态。
- `ground_checks.py` / `ground_diagnostics.py`：物理一致性、终点站立、数据分组及预测诊断。

状态 `s` 的前 375 维可 reshape 为 `[25,15]`，节点顺序为 base + MuJoCo 关节顺序。节点列为：角度、速度、电机力矩、地面广义关节负载、连杆质心相对基座位置 xyz、世界系地面力 xyz、相对基座接触位置 xyz、接触标志、连杆质心世界高度。全局 23 维为旋转矩阵前两列、基座线速度、MuJoCo 自由关节角速度、基座高度、相对基座全身质心 xyz、世界系质心速度 xyz、质心高度、基座向上向量。常用索引：基座高度 387、质心高度 394、向上分量 397。

训练文件 `exploration.npz` 的 `x,u,y,case,episode` 分别为当前观测、图式动作、下一观测、被动初始状态编号、探索轨迹编号。快照保存 qpos、qvel、电机延迟内部状态、ctrl、求解 warmstart 和时间；搜索允许恢复克隆状态，连续执行阶段不使用状态跳转。
