# 从躺姿起身（身体图式 / 接触图式探索）方案与现有管线对比：中文摘要

日期：2026-10-31。本文只做分析，没有改管线代码。为了确认两条事实，跑了两个小探针（各不到 2 秒）。英文详细版见 `analysis-getup.md`。

---

## 先回答三个问题

**(a) 现在的网络/架构逻辑和你的方案对得上吗？**
**理念上对得上，结构上对不上。**
- 两边的研究循环是同一个：
  - 现在："URDF 先验 → 主动辨识 → 约束优化 → 意外门控在线修正"；
  - 你的方案："探索 → 学映射 → 反解 → 重规划"。
- 现在的管线缺的是你方案里最外面那一层：**一边切换接触，一边把"想象出来的一串子目标"组合起来**。
- 决定性的事实有两条：
  - 现在的 WBC 把接触写死成"两只脚"：8 个鞋底角点，加上脚的 6 维锁定；
  - 仿真里**手臂、大腿、膝盖的碰撞体根本碰不到地面**（探针 1）。机器人"躺下来用手撑"在物理上就做不出来。

**(b) 差距有多大？**
**规划层和接触层差距大，估计层和动力学层差距小。**
- 最关键的差别：**固定接触 vs 切换接触**。从躺到坐、手脚撑、蹲、站，接触集合每一步都在变。
- 一条反直觉的结论：你说的"学习关节变化趋势 ↔ 质心变化"，**大部分不用学，可以直接算出来**。接触保持不变时，`ΔCoM = J_com·N_c·Δq`，用 URDF 加上已经辨识出来的质量就能算。
- 真正需要学或辨识的只有这几样：
  - 当前哪些部位在着地；
  - 什么时候会翻、滚、滑（接触切换）；
  - 外壳的形状和摩擦；
  - 持续大力矩下电机的极限。

**(c) 要改多少？**
大约 **35–45 % 原样复用，约 20 % 需要扩展，约 40 % 要新写**。这是按模块功能粗估的，不是精确工时。
- 能复用的是估计核心，正是项目目前科学结论的载体：
  - 力矩通道残差、噪声白化、摩擦联合辨识；
  - 三重门控、证据检验；
  - URDF 先验、BodyModel 的各种雅可比。
- 要新写的是"规划/组合层"和"接触模式层"：
  - 接触集合估计器；
  - "想象"反解器（把任意部位送到目标）；
  - 模式序列器；
  - 起身课程。

## 你方案的 6 点，逐条对照

1. **从躺姿开始，找被动稳定的静息状态**
   - 已有：仿真机器人和"真机误差模型"可以直接用，躯干和头能碰地。
   - 缺：四肢不碰地（改碰撞位掩码，再补大腿、手、膝的几何体）、躺姿复位、静息姿态搜索。
   - 另外，`fallen()` 现在把"躺着"当成失败。
2. **主动探索：动关节，看质心和身体各部位怎么变**
   - 已有：安全激励的思路（`exploration_targets`）和信息量排序（Fisher / 可观测性扫描）。
   - 缺：这些全都只在双脚支撑下有，躺姿下的探索动作和安全约束要新做。
3. **学接触：接触力 vs 关节力矩**
   - 这一条和现有代码**重合度最高**。`TorqueChannel` 本来就是"用关节力矩反推接触力"，噪声模型、白化、摩擦都做好了。
   - 缺：把 6×6 腿部反解推广到任意接触集合 `J_c(σ)ᵀ`，再加一个"哪种接触假设最能解释力矩"的假设检验。
   - 探针 2 给出了硬限制：
     - **同一个连杆上的压力分布不可观**，只能得到每个连杆的合力加压力中心；
     - **膝盖加整只脚掌平放（同一条腿）少 2 个可观方向**。
4. **学关节趋势 ↔ 质心的映射**
   - 已有：`BodyModel.com_jac`，每个控制周期都在用。
   - 缺：按接触集合投影（`N_c`），以及非光滑部分：翻、滚、滑。
   - 质量误差的影响：躯干多 0.8 kg 只会让关节对质心的雅可比整体缩放 6.8 %，而这一项已经辨识掉了。
5. **反解：想象质心或部位怎么动 → 生成动作，用最小努力组合出起身**
   - 已有：WBC 的 QP 就是"单步反解"，其中摆动脚任务本质上已经是"把某部位送到目标"。
   - 缺：多步/关键帧反解、努力目标函数（现在只有一个很小的 ‖τ‖² 正则项）、过渡姿态搜索、模式图和序列器。
6. **推广：头、手、腿都能"送到目标点"**
   - 已有：雅可比工具对任意部位都通用。
   - 缺：通用任务接口 `(部位, 点, 目标, 权重)`，以及在没训练过的部位和目标上的泛化评测。

## 把方案写成研究问题

- **"想象"**：不执行，在内部模型上做反解。给一个任务空间子目标（比如头抬高、质心挪向下一个支撑区），在当前接触集合下求满足平衡、摩擦锥、力矩和关节限位的动作。
  - 求不出解，本身就是信号：**得换接触了**。比如想抬腰，就得先把手撑下去。
- **"最小努力"**：慢速起身主要靠抵抗重力的保持力矩，所以建议这样定：
  - 最小化 `∫Σ(τ_i/τ_max,i)²`（归一化力矩平方，近似发热）；
  - 约束峰值力矩比 ≤ 0.8；
  - 再加稳定裕度。
  - 归一化很重要：pi+ 手臂只有 10 Nm，腿是 20 Nm。
- **"组合"**：接触模式图（例如仰卧 → 长坐 → 手脚撑蹲 → 蹲 → 站），边就是两种模式下都可行的过渡姿态，边的代价就是努力，然后做图搜索。

## 最小扩展路径（不离开现有理念和仿真）

- **G0 仿真修正**：四肢碰地、补几何体、躺姿复位、重新定义失败。真机仿真用网格外壳，内部模型用简化外壳，两者的差距就是要辨识的"接触图式误差"，和现在 θ* 与 θ̂ 的做法一样。
- **G1 仰卧探索**：从随机姿态松弛下来，找出静息姿态，作为安全锚点（相当于站立时的"静站"）。躺姿下重力方向在身体系里转了，**trunk_dz 和肢体质量变得可辨识**。现在 trunk_dz 站着测不出，只能用先验。
- **G2 接触集合估计器**：几何预测（平地上哪里最低）加力矩残差的假设检验，直接复用 `TorqueChannel` 的白化和证据检验。
- **G3 分模式辨识**：雅可比、静力平衡用解析计算；只有外壳接触参数和"翻/滚/滑"分类器用数据拟合，而且只在解析预测不够准时才上学习。
- **G4 "想象"反解器**：准静态 QP，"把部位 X 送到目标，同时努力最小"。头、手、脚、质心走的是同一套代码。
- **G5 序列器**：先用手写的模式图，图搜索加执行加意外门控重规划，自动发现模式图以后再做。

**仿真能验证的**：
- 接触可观性；
- 静息姿态和模式图的可行性；
- 准静态最小努力起身；
- 对 θ 误差的鲁棒性；
- 部位目标的泛化。

**必须上真机的**：
- 真实外壳在哪里着地、外壳摩擦；
- 电机持续发热的极限（仿真没有热模型）；
- 堵转时电流测力矩的精度；
- 探索时磕碰外壳的风险。

**依赖提醒**：9 次全摔主要摔在迈步阶段，起身的终点是静站，所以**一阶上不被走路问题卡住**。不过最后"蹲 → 站"会用到同一条 `delay_comp` 路径，最好先修好它或者关掉。

## 风险与证伪标准

- **F1 接触可观**：仿真里只用本体感觉判断接触集合，准确率必须 ≥ 95 %。如果估计器声称分得清探针 2 已经证明不可观的方向，就说明它在拟合噪声。不成立就意味着必须加触觉或接触开关，也就是改硬件。
- **F2 学习 vs 解析**：先测接触保持时解析 `J_com·N_c` 的预测误差。如果误差落在质心估计噪声以内，**在一个接触模式内学映射就没有理由**。只有当解析的翻/滚/滑预测错误率超过 10 % 时才引入学习。
- **F3 力矩可行性（建议第一个做，便宜又可能一锤定音）**：在名义模型上，能不能找到一串峰值力矩比 ≤ 0.8 的静态可行关键帧，从仰卧（或俯卧）一路到站立？找不到的话，起身就得靠甩动和动量，准静态的"想象"框架不够用。
- **F4 辨识对任务有用**：在失配真机上，用 θ̂ 规划要明显优于用名义 θ 规划。如果两者分不出差别（类似"零位辨识不改变走路结果"那次），说明起身主要被未建模的外壳和接触效应主导。
- **F5 部位泛化**：没训练过的（部位, 目标）组合，不能靠逐个调参才达标。
- **范围风险**：起身会在一个还没做完的问题（Phase 3 外层优化、走路摔倒）上再叠一个规划问题。先用手写模式图，研究重心才能留在"辨识"上。
