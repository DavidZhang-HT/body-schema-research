# Pi Plus 主动关节零位辨识

已在现有 Pi Plus 24 DOF URDF 的浮动基座 MuJoCo 场景中实现并运行。辨识对象是双腿12个关节的**编码器加性零偏**，不是机械限位归零；手臂和头部零位未辨识。上一轮步行实验及其结果保持不变。本实验单独验证零位辨识，不代表已经解决行走稳定性。

## 结果

每组对12个腿关节注入绝对值1°～3°、正负随机的固定零偏；模拟编码器白噪声标准差0.01°、IMU旋转向量噪声每轴标准差0.02°。三组注入/噪声种子为7、11、23。相同预算下比较信息增益选动作与预定顺序选动作。

| 种子 | 未补偿零偏RMSE | 固定顺序辨识RMSE | 主动辨识RMSE | 主动辨识最大单关节误差 |
|---|---:|---:|---:|---:|
| 7 | 2.110° | 0.555° | 0.093° | 0.134° |
| 11 | 2.022° | 0.453° | 0.133° | 0.321° |
| 23 | 1.838° | 0.749° | 0.132° | 0.255° |

六次运行均完成22.4秒物理仿真，没有触发中止或QP求解失败。流程为2.4秒初始站立、7个各2秒的辨识动作、3个各2秒的留出验证动作。每组120个辨识包、45个验证包。校准耗时为16.4仿真秒，不是CPU墙钟时间或真机实时性承诺。

主动辨识的留出姿态结果：

| 种子 | 双足等高残差RMSE：补偿前→后 | 足底法向分量残差：补偿前→后 |
|---|---|---|
| 7 | 1.806 → 0.054 mm | 3.300 → 0.031° |
| 11 | 0.261 → 0.078 mm | 1.723 → 0.031° |
| 23 | 2.930 → 0.090 mm | 2.664 → 0.032° |

“法向分量残差”是四个水平法向分量的RMSE按小角度转成度，不是完整三轴姿态角误差。留出姿态不参与动作选择和参数拟合。固定顺序对照也做在线参数补偿；比较改变的是动作选择顺序/子集。仅三个种子，不能据此证明对所有零偏、地面或机器人都优于其他方法。

## 实现

编码器观测与补偿符号：

```text
q_encoder = q_physical + offset + noise
q_corrected = q_encoder - estimated_offset
```

- `ZeroEstimator`的输入类型`Packet`只有24维编码器角和IMU四元数；无真实关节角、注入零偏、基座平移或真实足端位姿。
- 前向运动学只使用名义URDF和校正后的编码器。每个观测包构造5个约束：左右足底高度差为零，以及每个足底法向的两个水平分量为零。足端坐标使用原场景的足底局部点`[-0.025, 0, -0.05] m`。
- 足高残差以1 mm、法向残差以0.003 rad归一化，用有界鲁棒非线性最小二乘拟合12个偏差，范围±6°。估计不依赖注入参数的1°～3°分布，也不把该分布当作先验。
- 不要求双脚水平间距或偏航保持严格常数。在初版试验中，软接触产生了毫米级位移/足底偏航，永久锁定这些量造成约0.97°的估计RMSE；诊断记录保存在`zero_results/diagnostic_fixed_feet/`，未混入最终对照。
- 候选动作由名义模型IK生成：保持双足支撑的微蹲、横纵向位移和小幅躯干转动。有限池包含30个候选，最后3个留出验证，其余27个供选择。候选先通过IK残差和腿关节幅度筛选。
- 主动策略对当前数据的残差雅可比构造信息矩阵，选择预计`log det`增长最大的未执行候选。选择中的单位矩阵是数值设计正则，拟合及可辨识性评分不使用这个先验。固定顺序基线执行同一候选池的前7个。
- 每个动作的末0.6秒采样，约25 Hz；要求双脚各承载>15 N、总速度范数<0.45。传感器模型中的角速度/关节速度是理想值，没有额外速率噪声。
- 对数据雅可比做SVD，按最大奇异值的0.001计有效秩。单一站姿秩为5，不能单独确定12个偏差；多姿态最终达到12。只有至少执行两个探测动作且满秩时，才向控制器更新偏差；应用速度限制为每个4 ms周期每关节最多0.015°。
- 物理执行沿用关节力矩QP；时间步2 ms、控制周期4 ms，无基座外力、焊接或循环位姿重置。出现基座高度<0.24 m、IMU倾角>0.35 rad，或动作后段任一脚承载<3 N时中止。动作范围筛选与在线中止不是经过形式化证明的安全保证。

## 可辨识性的范围

最终满秩及上述精度依赖**已知正确运动学、水平地面、双足平放、正确的IMU安装方向**和充分多样的探测。未加入URDF几何误差、IMU安装偏差、编码器比例误差、柔性关节或迟滞；本次也未叠加上一轮的30%躯干质量误差。接触保留原仿真的软接触和摩擦。

估计器只用重力方向相关的足底法向和高度约束，不需要绝对航向。稳定控制器仍使用理想仿真基座平移与速度；估计器本身看不到基座平移。故这是传感器受限的零偏估计验证，并非完全实机化的状态估计/控制系统。实机IMU外参偏差或未知斜坡会与零位耦合，需要额外约束或联合标定。

## 文件和复现

- `zero_identification.py`：物理试验、传感器接口、估计器、主动选择、在线反馈补偿。
- `test_zero_identification.py`：单姿态不可辨识、多姿态可辨识、无噪声恢复、偏差符号及输入接口测试。
- `replay_zero_sensors.py`：只读传感器CSV重新估计，完全不读取真值。
- `summarize_zero.py`：对照图、CSV和按关节名称输出的校准配置。
- `render_zero.py`：从物理积分保存状态渲染的3.2倍速录像。
- `zero_results/active_seed7_calibration.json`：样例校准参数，单位rad，明确标为仿真验证用途。
- `zero_results/*_sensors.csv`：块编号、24个编码器角、IMU wxyz；不含真实零偏或真实关节位置。
- `zero_results/*.npz`、`*_seed*.json`：原始轨迹与评估结果。评估文件包含真值，供独立评分使用。

```bash
cd /workspace/pi_plus_experiment
export OPENBLAS_NUM_THREADS=1
.venv/bin/python test_zero_identification.py
.venv/bin/python zero_identification.py --seed 7 --selection active
.venv/bin/python zero_identification.py --seed 7 --selection fixed
# 同样命令可用 --seed 11 / --seed 23
.venv/bin/python summarize_zero.py
.venv/bin/python replay_zero_sensors.py zero_results/active_seed7_sensors.csv
.venv/bin/python validate_zero_results.py
.venv/bin/python render_zero.py
```

新环境用`requirements.txt`创建venv，先执行`build_model.py`生成本机路径场景，再运行上述命令。零位复现ZIP保留了所需的原始URDF与网格、来源说明、脚本和结果；原始资产来自HighTorque官方仓库提交`df3fcf16bf2cf645b8e3c24ee1e395d453f78f80`，适用其原始许可。录像是仿真积分轨迹的渲染，不是用IK动画代替物理执行。
