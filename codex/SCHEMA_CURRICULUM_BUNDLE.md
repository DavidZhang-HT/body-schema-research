# 第二版实验增量包

这是现有 `pi_plus_experiment` 项目的增量实验包，包含新代码、最终模型、合并后的训练／测试数据、全部控制轨迹、报告和图表。它不包含 Python 虚拟环境，也不重复打包原项目的 URDF、网格和基础仿真模块。

解压到现有 `pi_plus_experiment` 目录，使用该项目的 `.venv/bin/python`。训练、评估与复现命令见 `SCHEMA_CURRICULUM_STUDY.md`。读取报告和观看视频不需要运行代码。

`schema_v2_results/prediction_freeze.json` 保存了独立预测测试前的源文件和模型哈希；`control_freeze.json` 保存目标策略检查点与控制脚本哈希。原有实验的冻结文件保持不变。报告、录像和事后审计脚本不属于训练代码的冻结集合。

本轮实测没有证明课程优于混合训练，也没有证明已学会可靠的组合支撑或省力控制。请保留失败记录和数据分割。批量重跑训练会覆盖结果；新实验应另建版本目录，避免覆盖冻结证据。
